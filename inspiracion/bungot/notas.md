# Inspiración: bungot.com (la más relevante para BUNGOT_2026)

URL: https://bungot.com/collections/all

## Estilo visual
- Marca de premios/snacks para mascotas — el rubro más cercano al proyecto.
- Header verde azulado (#2f7a6b aprox) con título grande "PRODUCTOS" en amarillo pastel.
- Filtros tipo pill/chip con emojis: 🐕 Perros, 🐈 Gatos, 🦴 Huesos, 🧸 Juguetes.
- Tarjetas de producto con fondo de color sólido distinto por producto (naranja, celeste, amarillo, verde) + foto del snack + ilustración de un perrito.
- Precio y nombre del producto en la parte inferior de cada tarjeta, sobre franja oscura.

## Notas de layout
- Nav: shop / nuestra historia / suscribirse.
- Contador de productos arriba a la derecha (ej. "13 PRODUCTOS").
- Buen ejemplo de cómo combinar packaging real + ilustración simple de mascota.
