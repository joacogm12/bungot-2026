# Inspiración: gethapply.com

URL: https://gethapply.com/#newsletter

## Estilo visual
- Hero grande con tipografía bold/condensada tipo "happly" en beige/crema.
- Fondo cálido (crema #f5efd8 aprox) con fotos de gente riendo en primer plano.
- Banner superior con marquee animado ("use code FIRSTORDER...").
- Bloques de producto en tonos pastel (rosa salmón) con tipografía negra grande.
- Popup de descuento (10% off) al entrar, con foto de producto.

## Notas de layout
- Nav simple: shop / explore / subscribe, íconos de usuario y carrito a la derecha.
- Secciones tipo carrusel numeradas (01/03) para presentar variantes de producto con descripción + "mood" + "perfect for".
